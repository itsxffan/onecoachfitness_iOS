# Assets

This directory contains icon assets for the Outlook add-in.

## Required Icons:
- icon-16.png (16x16 pixels)
- icon-32.png (32x32 pixels)
- icon-64.png (64x64 pixels)
- icon-80.png (80x80 pixels)

These icons should be created with your branding and follow Microsoft's Office Add-in design guidelines.

For development, you can use simple placeholder icons or generate them using an icon generator.
