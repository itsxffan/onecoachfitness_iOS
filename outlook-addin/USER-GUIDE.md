## Getting Started

### Installation

Your IT administrator may have already installed this add-in for you. If not:

1. Open Outlook (Desktop, Web, or Mac)
2. Click **Get Add-ins** in the ribbon
3. Search for "OneCoach Email Manager"
4. Click **Add** to install

### First-Time Setup

When you first open the add-in:

1. Select any email message in Outlook
2. Click the **OneCoach Email** tab in the ribbon
3. Click **Manage Email** button
4. The task pane will open on the right side
5. Click **Sign In with Microsoft**
6. Enter your Microsoft 365 credentials
7. Grant the requested permissions
8. You're ready to go!

## Using the Task Pane

### Opening the Task Pane

1. Select an email message
2. Look for the **OneCoach Email** tab in the Outlook ribbon
3. Click **Manage Email**
4. The task pane opens on the right side

### Task Pane Layout

The task pane is organized into sections:

1. **Message Info** - Shows details about the selected email
2. **Categories** - Quick access to predefined categories
3. **Tags** - Add and manage custom tags
4. **Archive** - Archive the message
5. **SharePoint Integration** - Push to document libraries
6. **Status** - Shows success/error messages

## Email Categorization

### Using Categories

Categories help you organize and filter emails in Outlook.

**To add a category:**

1. Open the task pane with an email selected
2. Click one of the category buttons:
   - **Important** - Mark as high priority
   - **Follow Up** - Needs action
   - **Client** - Client-related emails
   - **Training** - Training materials

3. The button highlights to show it's active
4. The category is immediately applied to the email

**To remove a category:**

1. Click the highlighted category button again
2. The category is removed from the email

**Viewing categorized emails:**

1. In Outlook, go to the folder view
2. Group emails by category
3. Filter by specific categories
4. Create custom views based on categories

### Category Colors

Outlook automatically assigns colors to categories:

- Important: Red
- Follow Up: Yellow
- Client: Blue
- Training: Green

You can customize these colors in Outlook settings.

## Custom Tags

Tags give you more flexibility than categories. Use them for project names, client codes, or any custom organization system.

### Adding a Tag

1. Select an email
2. Open the task pane
3. In the **Tags** section, type a tag name
4. Click **Add Tag**
5. The tag appears in the list below

**Tag examples:**
- Project names: "Project Alpha", "Q4 Initiative"
- Client codes: "CLI-001", "CLIENT-ACME"
- Status indicators: "Urgent", "Waiting", "Review"
- Topic categories: "Budget", "Marketing", "Development"

### Removing a Tag

1. Find the tag in the tags list
2. Click the **×** button next to it
3. The tag is removed

### Tag Best Practices

- Use consistent naming conventions
- Keep tags short and descriptive
- Create a team-wide tagging system
- Combine with categories for powerful filtering

## Archiving Messages

Keep your inbox clean by archiving messages you've processed.

### Quick Archive

**From the ribbon:**
1. Select one or more emails
2. Click **Quick Archive** in the OneCoach Email tab
3. Messages are archived immediately

**From the task pane:**
1. Select an email
2. Open the task pane
3. Click **Archive Message**
4. Confirmation message appears

### Finding Archived Messages

Archived messages are moved to your Archive folder:

1. In Outlook, expand the folder list
2. Look for **Archive** folder
3. Click to view archived messages
4. You can move messages back to Inbox if needed

## SharePoint Integration

Push email content and attachments directly to SharePoint document libraries for team collaboration and record keeping.

### Prerequisites

- SharePoint site must be configured by your admin
- You need write permissions to the document libraries
- First-time use may require granting permissions

### Pushing to SharePoint

1. Select the email you want to push
2. Open the task pane
3. In the **SharePoint Integration** section:
   - Select a document library from the dropdown
   - Check/uncheck **Include attachments**
4. Click **Push to SharePoint**
5. Wait for confirmation message

### What Gets Pushed

When you push an email to SharePoint, the following is uploaded:

**Email content:**
- Subject line
- Sender information
- Date and time
- Full message body
- Saved as a .txt file

**Attachments (if checked):**
- All email attachments
- Uploaded to an "Attachments" subfolder
- Original filenames preserved
- All file types supported

### Available Libraries

Your administrator has configured these document libraries:

- **Client Documents** - Client-related emails and attachments
- **Training Materials** - Training content and resources
- **General Archive** - General email archive

### Accessing SharePoint Files

After pushing to SharePoint:

1. Open your SharePoint site in a browser
2. Navigate to the document library you selected
3. Find the uploaded files by date or name
4. Files are accessible to anyone with permissions
5. Collaborate using SharePoint features (versioning, co-authoring, etc.)

## Quick Actions

Some actions are available directly from the ribbon without opening the task pane.

### Quick Archive Button

1. Select one or more emails
2. Click **Quick Archive** in the OneCoach Email tab
3. Messages are archived instantly
4. A notification confirms the action

### Managing Multiple Emails

You can select multiple emails and use Quick Archive on all of them:

1. Hold Ctrl (Windows) or Cmd (Mac)
2. Click multiple emails to select them
3. Click **Quick Archive**
4. All selected emails are archived

## Tips & Best Practices

### Inbox Organization

1. **Process emails daily** - Use categories to triage quickly
2. **Archive processed emails** - Keep inbox for active items only
3. **Use consistent tagging** - Makes searching easier
4. **Push important emails to SharePoint** - Create a team-wide record

1. Open Outlook in the morning
2. Scan new emails

**Team collaboration:**

## Troubleshooting

### Add-in Not Visible

**Solution:**
1. Check if add-in is installed (Get Add-ins > My add-ins)
2. Restart Outlook
3. Contact your IT administrator
4. Check you're selecting an email (add-in only works in read mode)

### Sign-In Issues

**Solution:**
1. Ensure you're using your work Microsoft 365 account
2. Check internet connection
3. Clear browser cache and cookies
4. Try signing out of Microsoft 365 and back in
5. Contact IT if permissions are needed

### Categories Not Applying

**Solution:**
1. Wait a few seconds for sync
2. Refresh the email view
3. Check if you have edit permissions
4. Restart Outlook if issue persists

### SharePoint Upload Fails

**Solution:**
1. Verify you have write permissions to the library
2. Check if file names are too long (max 128 characters)
3. Ensure you're connected to the network
4. Try uploading a different email to test
5. Contact IT if problem continues

### Task Pane Doesn't Open

**Solution:**
1. Select an email first
2. Check if another add-in is blocking
3. Close and reopen Outlook
4. Disable and re-enable the add-in
5. Clear Office cache (contact IT)

### Performance Issues

**Solution:**
1. Close other applications to free memory
2. Reduce number of browser tabs
3. Archive old emails in Outlook
4. Clear Outlook cache
5. Restart your computer
